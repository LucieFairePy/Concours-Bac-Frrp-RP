# Banque d'images du kit V4

Dépose ici les visuels du kit, **sous leur nom exact**. Chaque place a un
repli dans `assets/img/` : tant que le fichier n'est pas déposé, le repli
s'affiche, et il suffit de déposer le fichier pour qu'il prenne sa place,
sans toucher au code.

La liste complète, avec le sujet attendu et le repli actuel, est affichée
dans le portail : **Administration → Banque d'images**. La source est
`js/data/images.js`.
